# 🧠 Thinkty

**Thinkty** est une application mobile développée en **React Native** avec **Expo** et **Supabase**.  
Elle permet aux utilisateurs de **gérer leurs tâches**, **stocker des notes**, et **enregistrer des mots de passe en toute sécurité**.

## 🚀 Fonctionnalités

### ✅ Checklist (Tâches)
- Ajouter une tâche
- Supprimer une tâche
- Marquer une tâche comme terminée

### 📝 Notes
- Ajouter des notes avec un **titre et du contenu**
- Supprimer des notes
- Accéder aux détails d'une note
- Marquer certaines notes comme **privées** (A venir)

### 🔐 Coffre-fort de mots de passe
- Stocker des mots de passe en toute sécurité
- Accéder aux mots de passe avec un **mot de passe principal**
- Chiffrement des données

## 🛠️ Technologies utilisées

- **React Native** avec **Expo**
- **Supabase** (Base de données et authentification)
- **React Navigation** (Gestion de la navigation)
- **Styled Components** (Personnalisation de l'UI)
